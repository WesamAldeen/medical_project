# 🩺 Medical Directory & Doctor Management Platform

A full-stack web application designed to connect patients with healthcare providers, specialist clinics, and medical centers. The platform offers seamless directory search, dynamic doctor onboarding, analytics tracking, and an administrative control panel.

🌐 **Live Demo:** [docguide.free.je](https://docguide.free.je/)

---

## ✨ Features

- **Doctor Directory & Filtering:** Search and filter medical professionals by specialty, state/governorate, and city.
- **Onboarding Survey System:** Simple registration interface for doctors to submit profile details, contact info, and medical credentials.
- **Secure File Processing:** Automated profile image upload handler with file-type validation and unique filename generation.
- **Admin Dashboard:** Full CRUD functionality to approve, edit, and manage doctor profiles and specialties.
- **Analytics & Visitor Insights:** Integrated **Google Analytics (GA4)** to track traffic volume, monitor visitor device types (Mobile, Tablet, Desktop), and log visit timestamps to analyze user behavior.
- **Security First:** Built with PHP PDO prepared statements and transaction handling to protect against SQL Injection and XSS attacks.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Tailwind CSS v4, JavaScript (ES6+)
- **Backend:** PHP
- **Database:** MySQL (PDO Driver)
- **Analytics & Tracking:** Google Analytics (GA4)
- **Styling & Icons:** Tajawal Font, Tailwind CSS
